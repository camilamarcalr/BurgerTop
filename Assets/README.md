# Mídias do BurgerTop

Esta pasta guarda os arquivos visuais usados no projeto. Eles ficam separados do HTML, CSS e JavaScript para facilitar a organização.

- [images](images/README.md): fotos dos produtos, banner, referências de layout e versões mais leves das imagens.
- [videos](videos/README.md): vídeo de apresentação usado no banner.

Os arquivos originais foram mantidos. As versões WebP foram criadas a partir das fotos fornecidas, para que a página carregue menos dados sem precisar trocar as imagens.

Os READMEs das duas pastas explicam quais arquivos aparecem no site e como são usados. A marca no cabeçalho é feita com texto; ela não depende de um arquivo de logo.

O repositório mantém os originais e as referências para documentar o trabalho. `npm run build` copia para `dist/Assets` apenas as mídias usadas pelo site, sem mover ou renomear os arquivos de origem.
