# Guias do BurgerTop

Esta pasta reúne as orientações para entregar e publicar o projeto:

- [GITHUB.md](GITHUB.md): primeiro commit e envio, partindo da pasta ainda sem Git.
- [PUBLICACAO.md](PUBLICACAO.md): build, Vercel, domínio e configuração do Supabase.
- [VERIFICACAO.md](VERIFICACAO.md): mudanças realizadas, testes executados e limites conhecidos.

Para executar o site, comece pelo [README principal](../README.md). Para recriar o banco em outro projeto, siga o [guia do Supabase](../supabase/README.md). Os comandos dos guias são executados na raiz do BurgerTop. Substitua os exemplos como SEU_USUARIO antes de usar.
